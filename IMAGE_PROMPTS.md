# Toi Māori — Image Prompts (ChatGPT)

70 lesson images + 1 character sheet. Every slide shows an **“Image to come”** box until you add the file with the **exact name** below into the matching folder. PNG, JPG or WEBP all work.

## How to use
1. Open ChatGPT (image generation on). Start with the **Character sheet** prompt — keep that chat going and attach the sheet (or say “same characters as above”) for any image with children or a teacher.
2. For each image: copy the whole grey box for that file (the style is already included) and paste it into ChatGPT. Ask for 16:9 landscape.
3. Save with the exact filename, e.g. `L01-title.png`.
4. On GitHub (web): open `maori-art/images/L01` → **Add file → Upload files** → drop the images → Commit. (Or copy them into the phone drive folder and Commit & Push from the dashboard.)

## Style block (already included in every prompt — shown here for reference)
> Bold flat-colour comic-book illustration with thick black ink outlines, a limited palette of red ochre, black, warm cream and a little greenstone teal, subtle halftone dot shading, warm and welcoming, suitable for Year 5–6 children. Wide 16:9 landscape (1792×1024). IMPORTANT: no text, letters, words, numbers, signs or labels anywhere in the image.
> Respectful depiction: show only generic traditional-STYLE patterns (koru spirals, triangle rows, lattice, scrolls) — do not copy any specific named carving, meeting house or artwork; do not draw tā moko on any face or body; do not depict atua (gods) or ancestors; children and teacher are kind, ordinary NZ classroom people.

## About authenticity (please read)
AI pictures of patterns are *inspired illustrations*, not real taonga. For the **Look** slides the app also links to real photos on Te Ara and museum sites — use those on the big screen for the real thing. If you prefer real photos in the slots, save them with the same filenames — but only use images you have permission to use (many museum collections state their licence).
